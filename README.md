A one-line deadpan weather forecast for a city that does not exist: heavy rain of unposted letters over Quibblewick, highs of 11 degrees, and one postman finally catching up on 40 years of deliveries. A dry, deadpan TV meteorologist judge compares forecasts head to head; one winner takes the $2 reward.

## Run it

```sh
python3 main.py
```

Writes the forecast to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
